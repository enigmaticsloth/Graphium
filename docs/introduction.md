# Graphium — Project Introduction

## Traditional Chinese

**Graphium** 是一套以 **Python 3** 開發的實驗數據繪圖與統計分析工具，透過 Streamlit 提供瀏覽器操作介面。匯入 Excel、CSV 或 TSV 資料後，即可製作長條圖、折線圖、箱型圖、小提琴圖、散佈圖、圓餅圖與熱圖。程式整合 SciPy 與 statsmodels，內建自動統計檢定、自選組別的 t-test，以及 FDR／Bonferroni 多重比較校正；也能自訂座標範圍、圖表長寬、組別名稱與統計星號的顯示方式。圖表可匯出為 300 DPI 的 PNG／TIFF，或 SVG／PDF 向量格式，方便用於研究報告、簡報與論文製圖。

Repository: [enigmaticsloth/Graphium](https://github.com/enigmaticsloth/Graphium)

## English

**Graphium** is an experimental data visualization and statistical analysis tool built with **Python 3** and a browser-based Streamlit interface. Import Excel, CSV, or TSV files to create bar, line, box, violin, scatter, pie, and heatmap figures. Powered by SciPy and statsmodels, it includes automatic statistical test selection, t-tests between selected groups, and FDR or Bonferroni multiple-comparison correction. Users can customize axis ranges, figure dimensions, group labels, and the visibility of statistical annotations. Figures can be exported as 300 DPI PNG/TIFF images or SVG/PDF vector files for research reports, presentations, and scientific publications.

Repository: [enigmaticsloth/Graphium](https://github.com/enigmaticsloth/Graphium)
